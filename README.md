🛍️ Retail Superstore Dashboard | Power BI

An interactive Retail Sales Analytics Dashboard built using Microsoft Power BI to analyze sales performance, profit, product categories, and regional business trends.

📊 Project Overview

The Retail Superstore Dashboard transforms retail sales data into meaningful visual insights. It helps users understand business performance, identify profitable product categories, and explore sales trends to support data-driven decision-making.

🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track key performance indicators (KPIs).
- Compare sales across product categories and regions.
- Identify top-performing products and segments.
- Present business insights through interactive visualizations.

🛠️ Tools & Technologies

- Microsoft Power BI — Dashboard development and data visualization
- Power Query — Data cleaning and transformation
- DAX — Measures and calculations, where applicable
- Excel / CSV — Data source, depending on the dataset used

📈 Dashboard Features

- KPI cards for important business metrics
- Sales and profit analysis
- Category and sub-category comparisons
- Regional performance analysis
- Interactive charts and filters
- Business performance overview

🚀 How to Use

1. Download "retail_styled.pbix" from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. Refresh the data if required and if the source is available.
4. Explore the dashboard using its interactive filters and visualizations.

💡 Business Value

This dashboard demonstrates how business intelligence tools can turn retail data into actionable insights. It supports performance monitoring, product comparisons, and regional sales analysis.
